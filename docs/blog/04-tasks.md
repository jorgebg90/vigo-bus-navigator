# Building Vigo Bus Navigator: Tasks

The task phase translates the approved design into 78 dependency-ordered tasks. Tests come before implementation within each user story, and the MVP stops after the frequency experience is independently usable from bundled data.

The task review added explicit coverage for browser engines, recent-view retention, Lighthouse performance validation, privacy auditing, port ownership, and the Communicator gate. This keeps those decisions visible during implementation instead of leaving them as review-time surprises.
