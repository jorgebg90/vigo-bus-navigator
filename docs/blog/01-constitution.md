# Building Vigo Bus Navigator: Constitution

The project began by ratifying a constitution for a browser-first public-good PWA. The governing choices are static GitHub Pages hosting, one Cloudflare Worker exception for the legacy arrivals proxy, hexagonal boundaries, local-only user state, WCAG 2.2 AA, and English development artifacts.

The constitution is deliberately restrictive. It keeps the product deployable at zero recurring cost and makes privacy, testability, and mobile-first performance architectural constraints rather than late review concerns.
